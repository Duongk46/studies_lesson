# English Learning Pages

Static site deployed on Vercel. Routes are configured in `vercel.json`.

| Route | Page |
|-------|------|
| `/`   | redirects to `/a` |
| `/a`  | English Lessons — Interactive Practice (`English_Lessons.html`) |
| `/b`  | English Communication Mastery — Complete Guide (`English_Mastery_Complete.html`) |
| `/c`  | English Mastery Pro — Full Guide (`English_Mastery_Pro.html`) |

## Deploy

This repo is connected to Vercel and auto-deploys on every push to the default branch.
No build step — it's served as static files.
